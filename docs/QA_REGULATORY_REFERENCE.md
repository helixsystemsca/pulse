## Edit / create / archive (Josh — company admin)

16. **New card** / **Add guidance document**: add a local document. It appears in filters and in header Search / Ask after reload.
17. **Archive** a card with confirm. It leaves the active library; **Show archived** + **Restore** brings it back.
18. API restart must **not** insert a new starter catalog. Existing cards stay as Josh left them (including archived).
19. Do not paste copyrighted code. Leave verification as Unverified until you confirm the URL.
